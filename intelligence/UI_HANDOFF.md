# 포털 대시보드 개편 — 2026-10-19

- 브랜치: feat/portal-dashboard. 첫 화면 index.html을 요약 지표 4개, 최근 보고서 변화, 발행 차단 이유, 상세 메뉴 6개로 구성.
- 기존 index.html 내용은 research.html로 보존. 기존 portal.js 데이터 수집·검색·검증 동작 유지.
- intelligence/index.html은 상세 탭으로 직접 접근하는 hash route 및 뒤로 가기 지원. 두 상세 화면에서 대시보드 복귀 가능.
- dashboard.js는 기존 JSON을 읽기만 한다. KRX 관측 수와 기준일, 보고서 날짜와 계산/실행 시각을 별도 표시. 결측/실패는 0 또는 정상으로 표시하지 않는다.
- 기존 Playwright CI에 홈페이지 요약/모바일 가로 넘침/상세 이동/뒤로 가기 검사 추가. 로컬 환경의 Sites 지침상 브라우저 실행은 생략하고 원격 CI로 검증.
- 인증 미적용: 현재 공개 GitHub Pages와 공개 저장소는 HTML 비밀번호로 보호되지 않는다. 비밀번호를 클라이언트 코드/공개 저장소에 저장하지 않았다. 서버 측 인증 호스팅 및 공개 데이터 경로 정리가 필요하며, 사용자 요청 비밀번호는 대화에만 보존한다.
- FULL 보고서 자동 작성기는 여전히 후속 작업. UI 개편이 정식 보고서 발행 또는 연구 검증 완료를 뜻하지 않는다.
